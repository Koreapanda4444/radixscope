# RadixScope 2.1.0

한국어 | [English](../../releases/2.1.0.md)

데스크톱 계산 취소, 비트 편집, Windows x64 데스크톱 패키지를 추가한 버전입니다.
정확한 숫자 처리 코어와 명령줄의 계산 규칙은 유지합니다.

- 네 작업 화면의 계산을 별도 프로세스로 실행하고 Cancel과 앱 종료 때 정리합니다.
- 입력 변경 시 이전 계산과 출력을 버리며 취소한 결과는 최근 기록에 저장하지 않습니다.
- Programmer 결과 비트를 편집하면 부호 해석·입력 패턴·바이트 표현을 함께 갱신합니다.
- IEEE 754의 부호·지수·가수를 구분하며 NaN 페이로드와 시그널링 비트를 보존합니다.
- 페이지당 비트 버튼을 최대 32개로 제한해 기본 창에서 binary64 버튼이 겹치지 않습니다.
- Qt 결과 신호에서 임의 크기 Python 정수를 Qt 정수로 강제 변환하지 않도록 수정합니다.
- Windows x64 ZIP에 Python·Qt·앱 아이콘·버전 정보·문서를 포함합니다.
- CI에서 압축을 푼 패키지의 GUI·계산 프로세스·비트 편집·취소를 검증합니다.

성공한 [Quality 실행](https://github.com/Koreapanda4444/radixscope/actions/workflows/quality.yml)의
`RadixScope-windows-x64` 산출물을 내려받고 두 ZIP을 풀어
`RadixScope/RadixScope.exe`를 실행하세요. `_internal` 폴더는 실행 파일과 함께 유지합니다.
[설치 안내](../install.md)와 [데스크톱 사용법](../desktop.md)을 참고하세요.

2.0.0의 설정·기록 형식과 저장 위치를 유지하므로 별도 이전은 필요하지 않습니다.
데스크톱 결과 전달 제한은 8 MiB이며 기존의 정확한 변환·과정 표시 제한도 적용합니다.
패키지는 CI 산출물로 제공하며 공개 릴리스나 PyPI 자동 게시 설정은 없습니다.
