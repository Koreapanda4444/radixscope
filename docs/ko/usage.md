# 데스크톱 사용법

한국어 | [English](../usage.md)

`radixscope-gui`, `python -m radixscope.gui` 또는 Windows EXE로 실행합니다.
상단 탭과 단축키로 네 작업 화면을 선택합니다.

| 단축키 | 화면 | 용도 |
| --- | --- | --- |
| Ctrl+1 | 진법 변환 | 진법 변환과 선택형 변환 과정 |
| Ctrl+2 | 수치 계산 | 정확한 수식과 고정 비트 정수 연산 |
| Ctrl+3 | 숫자 분석 | 숫자 표현과 전문 분석 |
| Ctrl+4 | 일괄 변환 | 줄 단위 변환 |
| Ctrl+H | 최근 기록 | 기록 검색·복원·내보내기 |

## 결과와 계산 실행

결과 탭은 관련 정보를 구분·항목·값으로 묶고, 텍스트 리포트는 전체 보고서를 표시합니다. 행을 선택하고
선택 항목 복사·Ctrl+C·더블클릭으로 원래 값을 복사할 수 있습니다. 전체 복사는
텍스트 리포트를 복사합니다. 표의 긴 미리보기가 줄어들어도 복사·내보내기 값은 유지됩니다.
상세 항목을 펼치거나 필터로 원래 데이터 경로까지 검색하면 부동소수점 경계 등 추가 정보를 확인할 수 있습니다.

재사용 / 내보내기에서 정확한 값 또는 원시 비트를 다른 화면으로 전달하고
텍스트·JSON·CSV로 저장합니다. 원시 비트 전달은 패턴과 폭을 유지합니다.
형식 비교·일괄 변환에서는 전달할 행을 선택하고, 숫자 비교에서는 재사용할 숫자를 고릅니다.

실행하면 별도 프로세스에서 계산합니다. 취소하거나 입력을 바꾸면 실행 중인 작업을
중지하고 이전 결과를 무효화합니다. 입력 상태가 일치하는 응답만 적용하며,
잘못된 입력에서는 복사·재사용을 비활성화합니다. 앱 종료 시 계산 프로세스도 종료합니다.
응답 한도는 8 MiB입니다.

표시 중인 입력 컨트롤에 맞춰 높이를 자동 조정합니다. 구분선을 드래그하면 수동 높이를
존중하면서 창 크기에 맞춰 보정하고, 일부러 좁힌 입력은 스크롤할 수 있습니다.
구분선을 더블클릭하면 현재 옵션에 맞는 자동 배치로 복원합니다. 최소 창 크기는 640 × 480이며, 작은 창에서는
입력을 스크롤하면서 실행 버튼과 결과를 사용할 수 있습니다. 구분선·상세 패널·비트 묶음
설정은 숫자 입력과 별도로 저장합니다.

## 진법 변환

숫자 모드는 선택한 원본 진법을 사용합니다. 자동 모드는 지원하는 입력 문법을 인식하며,
형식 안내와 자동 입력 사용 버튼으로 전환할 수 있습니다. 분수·순환소수는 정확한 유리수로
유지합니다. 정확한 출력의 소수부 미리보기는 최대 1000자리이고, 제한되면 부분 전개로
표시합니다. 반올림 출력에서는 자릿수와 다섯 가지 반올림 방식을 고릅니다.

**반올림 비교**를 켜면 **반올림 비교** 결과 탭에서 버림·Half-up·Half-even·내림·올림을
한 번에 확인할 수 있습니다. 비교 표 위의 **진법**과 소수부 **자릿수**는 대상 진법 기준이며, 자릿수는 일반 반올림 출력과 공유합니다.
일반 출력을 반올림하더라도 비교에는 원래의 정확한 입력값을 사용합니다.
`2.5`를 10진법 소수부 0자리로 비교하면 순서대로 `2`, `3`, `2`, `2`, `3`입니다.
비교 결과 복사는 다섯 행 전체를 복사하며, 행을 선택하면 선택한 행만 복사합니다.
선택형 기능이므로 일반 변환·CLI·일괄 변환 동작은 그대로입니다.

프리셋으로 자주 쓰는 진법 또는 10진수와 2·16진수 쌍을 설정합니다. 직접 진법을 바꾸면
직접 설정으로 전환됩니다. 빠른 교환은 대상 진법 하나를 골라 원본과 교환합니다.
필요하면 정확한 분수로 입력을 다시 표현하므로 반올림된 미리보기 때문에 원본 값이 바뀌지 않습니다.

변환 과정 보기를 선택하면 상세 탭을 사용할 수 있습니다. 대상 진법과 소수부 단계 제한을
설정하고 정수부 나눗셈·소수부 곱셈을 확인합니다. 순환 구간은 강조하며,
단계 제한에 도달한 부분 추적을 유한소수로 판정하지 않습니다.

## 수치 계산

정확한 수식 계산은 혼합 진법 리터럴과 유리수 연산을 사용합니다. 출력 진법과 반올림을
따로 지정합니다. 비트 연산에는 정수가 필요하며 `//`, `%`는 분수도 받습니다.
연산자 우선순위는 Python 방식을 따릅니다.

고정 비트 정수에서는 비트 폭, Signed 여부, 숫자·원시 비트 입력, 연산과 피연산자를
지정합니다. 정확한 수학적 결과·오버플로·래핑 결과를 구분합니다.
**8/16/32/64비트 결과 비교**를 켜면 같은 연산을 각 비트 폭으로 계산해 결과·오버플로·패턴을 보여줍니다.
각 폭을 독립적으로 계산하므로 선택한 기본 폭이 실패해도 다른 폭의 결과를 확인할 수 있습니다.
예를 들어 Unsigned `300 + 1`에서 8비트를 선택하면 8비트 행은 범위 오류이고,
16·32·64비트 행은 `301`입니다. 잘못된 숫자 문법이나 지원하지 않는 연산자는 전체 입력 오류로
표시합니다. 수학적 결과·오버플로 열은 산술 연산에 적용하며, 비교에는 비트 추출 전 결과를 사용합니다.
Signed의 `shr`는 부호를 확장하고 `lshr`는 0을 채우며 시프트 횟수는 10진수입니다.
비트 범위 추출은 결과의 LSB 0 기준 오프셋과 폭을 사용하고 선택한 부호 해석을 적용합니다.
결과 비트를 편집하면 연산이 Inspect로 전환됩니다.

정수 보고서에는 Signed/Unsigned 최소 비트 폭, 8·16·32·64비트 수용 여부와 선택 범위가
포함됩니다. 음수에는 Unsigned 최소 폭이 없습니다. GUI 정수 폭은 1~4096비트입니다.

## 숫자 분석

숫자·수식 입력, 자료형, 비트 폭, 부호와 엔디언을 고릅니다. 숫자 입력은 수학적 값을
변환하고 원시 비트는 입력 패턴을 재해석합니다. 정수가 선택 범위를 벗어나도 정확한 값과
필요한 폭을 표시하며, 범위 오류와 함께 비트 패턴을 비워 둡니다. 바이트는 전용 버튼으로 복사합니다.

비트 편집 및 인접 값 탐색을 펼치면 Hex와 비트를 편집할 수 있습니다.
4비트 묶음은 Hex 자리, 8비트 묶음은 숫자 바이트에 대응합니다. LSB를 0번으로 세고
부호·지수·가수 영역을 구분하며, 한 페이지에 최대 32개 비트를 표시합니다.
비트·Hex 편집은 관련 표현을 갱신합니다. 엔디언은 수학적 값이 아닌 바이트 순서를 바꿉니다.

분석 방식에서 다음 기능을 선택합니다.

- **숫자 표현:** 정수 해석 또는 binary16·bfloat16·binary32·binary64 인코딩·디코딩,
  정확한 오차·상대 오차·ULP를 표시합니다. 특수값 옵션에서 음의 0과
  Quiet/Signaling NaN 페이로드를 지정합니다. 원시 비트 디코딩은 모든 비트를 유지하며,
  인접 값·경계 탐색은 현재 부동소수점 패턴에 적용합니다.
- **부동소수점 형식 비교:** 같은 정확한 입력을 네 형식으로 직접 인코딩하고
  오차·유효 정밀도·중간 반올림 차이를 표로 비교합니다.
- **숫자 비교:** 같은 진법·자료형·폭 설정으로 두 입력의 수학적 대소 관계,
  차이·절댓값 차이·진법별 표현을 확인합니다. 표현 가능한 패턴에는 XOR, 다른 비트 위치와
  Signed/Unsigned 차이도 표시합니다. 비트 영역을 펼치면 차이를 강조합니다.
  정수 패턴이 없는 분수도 수학적으로 비교할 수 있으며 NaN의 대소 관계는 정의하지 않습니다.
- **부동소수점 연산 실험:** 두 정확한 수식 또는 원시 패턴을 입력하고 형식과 사칙연산을
  선택합니다. 인코딩된 피연산자, 피연산자를 먼저 반올림한 경로, 원래 값을 정확히 계산한 뒤
  한 번 반올림한 경로를 구분합니다. 입력 변환 플래그·연산 플래그·원래 수학적 값과의 오차를
  따로 표시합니다. **IEEE 반올림**에서 최근접 짝수(기본), 0 방향, +∞ 방향, −∞ 방향을 선택합니다.
  작고 정확하지 않은 결과에는 반올림 후 판정에 따라 언더플로를 표시합니다.
  유한하지 않은 결과에는 유한 유리수 오차를 부여하지 않습니다.

## 일괄 처리·환경설정·기록

일괄 변환은 숫자·수식·자동 모드에서 비어 있지 않은 줄을 처리하고 원래 줄 번호와
개별 오류를 유지합니다. 출력 진법, 반올림, 정확한 출력과 행 한도를 지정합니다.
요약에서 오류·제한·미처리 입력을 확인하며, 한 오류 때문에 성공한 다른 행을 버리지 않습니다.

설정 → 환경설정에서 한국어·영어와 시스템·라이트·다크 테마를 선택합니다.
언어를 바꿔도 입력·계산 결과는 유지하고, 내보내기 키와 숫자 문자열은 공통 형식을 사용합니다.

최근 기록은 처음에 숨겨져 있습니다. 입력·결과·작업 종류를 검색하거나 종류별로 필터링합니다.
캐시가 있는 결과는 바로 복원하고, 큰 보고서는 입력·옵션을 복원해 다시 계산합니다.
기본 기록은 20개, 설정 범위는 1~100개이며 보고서 캐시는 항목당 256 KiB입니다.
기록을 꺼도 현재 작업 화면 설정은 유지합니다.

설정은 스키마 1과 32 MiB 한도를 유지합니다. 지원하는 예전 작업은 새 화면으로 옮기고
삭제된 버퍼·레이아웃 작업은 제외합니다. 원자적 저장으로 실패 시 이전 파일을 보존합니다.
CLI는 GUI 설정을 변경하지 않습니다.
