# 데스크톱 앱 사용법

한국어 | [English](../usage.md)

`radixscope-gui`, `python -m radixscope.gui` 또는 Windows EXE로 실행합니다.
사이드바는 분석·계산·비교 도구를 묶어 보여주며 단축키 순서는 다음과 같습니다.

| 단축키 | 작업 화면 | 용도 |
| --- | --- | --- |
| Ctrl+1 | 변환 / Conversion | 정확한 진법 변환과 수식 |
| Ctrl+2 | 변환 과정 / Trace | 나눗셈·나머지 단계 |
| Ctrl+3 | 정수 연산 / Programmer | 고정 비트 정수 연산 |
| Ctrl+4 | IEEE 754 | 정밀도 분석과 네 형식 비교 |
| Ctrl+5 | 숫자 분석 / Number Inspector | 숫자·원시 비트·바이트 동기화 |
| Ctrl+6 | 바이트 분석 / Byte Inspector | 범위 선택과 비트필드 |
| Ctrl+7 | 이진 비교 / Binary Comparison | XOR와 필드 차이 |
| Ctrl+8 | 일괄 변환 / Batch Conversion | 줄별 숫자·수식 처리 |
| Ctrl+H | 최근 기록 | 검색과 복원 |

## 공통 조작

결과는 필드 검색이 가능한 표로 표시하며 텍스트 보고서에서 전체 내용을 볼 수 있습니다.
행을 선택하고 선택 복사 또는 Ctrl+C를 누르면 원본 값을 복사합니다.
전체 복사는 현재 텍스트 보고서를 복사합니다.
표에서 긴 값의 미리보기를 줄여도 복사·내보내기로 전체 값을 사용할 수 있습니다.

재사용·내보내기를 펼치면 화면 간 전달과 텍스트·JSON·CSV 내보내기가 나타납니다.
수치 전달은 가능한 경우 정확한 값을, 원시 비트 전달은 패턴과 폭을 유지합니다.
해석은 목적 화면의 자료형을 따릅니다. 이진 비교로 전달하면 왼쪽 입력만 채우고
오른쪽 입력을 기다립니다. 부동소수점 형식 비교·일괄 변환에서는 선택한 행을 전달합니다.

계산은 별도 프로세스에서 실행합니다. 취소하거나 입력을 바꾸면 해당 프로세스를
중단하고 이전 결과를 지웁니다. 계산 시작 때의 입력과 현재 입력이 같을 때만 결과를
받습니다. 잘못된 입력은 오류를 표시하고 복사·내보내기·재사용을 비활성화합니다.
창을 닫으면 진행 중인 계산을 중단합니다. 계산 응답은 8 MiB로 제한합니다.

입력과 결과 사이 구분선으로 높이를 조절합니다. 선택 도구는 필요할 때 펼치고,
작은 창에서는 표와 입력 영역을 스크롤합니다. 최소 창 크기는 640 × 480입니다.
구분선 위치와 패널 표시 여부는 계산 입력과 별도로 복원합니다.

## 변환과 과정

변환은 숫자(직접 진법 선택)·수식·자동 모드를 지원합니다.
문법 안내를 보고 자동 모드로 전환하면 인식된 문법을 적용합니다.
정확한 변환은 소수부 최대 1000자리를 표시하고 부분 전개와 해당 진법을 명시합니다.
원래 유리수는 유지합니다. 정확한 출력을 끄면 자릿수와 반올림 방식을 고릅니다.

과정은 정수부 나눗셈, 소수부 곱셈과 순환 구간을 보여줍니다.
소수부 최대 단계 수를 조절할 수 있습니다. 부분 과정의 `complete=False`는
유한소수라는 판정과 다릅니다.

## 숫자 분석과 정수 연산

숫자 분석은 2·8·10·16진수, 부호 있는 값과 없는 값, 비트·Hex 편집, 고정 폭과
엔디언 바이트를 함께 보여줍니다. 정수 또는 네 부동소수점 형식을 선택하세요.
원시 패턴 옵션은 숫자를 비트 패턴으로 재해석하며, 일반 입력은 수학적 값입니다.
정수는 선택한 폭에 들어야 합니다. 부호 설정은 고정 패턴의 해석을 바꿉니다.

비트나 Hex를 편집하면 원시 패턴 입력으로 바꾸고 다른 표현을 갱신합니다.
엔디언 변경은 직렬화 순서를 바꾸며 원래 숫자를 바이트 교환한 값으로 바꾸지 않습니다.
비트는 한 페이지에 최대 32개를 표시하고 클릭 또는 포커스 후 Space로 전환합니다.

기존 Programmer 화면은 정수 연산으로 유지합니다. 산술 결과는 정확한 값,
오버플로와 래핑 값을 구분합니다. 결과 비트를 편집하면 Inspect로 전환해서
이전 산술 연산을 다시 적용하지 않습니다. GUI 정수 폭은 1~4096비트이며,
Core에도 명세에 적힌 작업 한도가 적용됩니다.

## IEEE 754

인코딩은 정확한 수식·NaN·무한대를, 디코딩은 선택 진법의 원시 숫자를 받습니다.
binary16·bfloat16·binary32·binary64 중 선택합니다.
부호·지수·가수부를 구분하고 부호 있는 0, quiet/signaling NaN과 페이로드를 보존합니다.
정의할 수 있는 경우 정확한 유리수 표현값·오차·ULP 간격을 보여줍니다.

부호 있는 0 옵션은 0 인코딩에, NaN 옵션은 NaN 인코딩에 적용합니다.
signaling NaN에는 0이 아닌 페이로드가 필요합니다.
디코딩에서는 비활성화된 인코딩 옵션을 무시합니다.
비트 편집은 디코딩으로 전환하며 패턴을 유지합니다.

이전·다음으로 인접 표현값을 탐색하고 경계 선택으로 0, 최소 비정규수,
최소 정규수, 최대 유한수와 무한대 패턴으로 이동합니다.
형식 비교는 같은 원본의 네 형식 표현, 유효가수 비트와 중간 반올림 차이를 표로 보여줍니다.
복사·다른 화면 전달 전에 비교 행을 선택하세요.

## 바이트와 비트필드

바이트 분석은 Hex·Binary·Base64·UTF-8을 받습니다.
오프셋·길이나 표 선택으로 범위를 고릅니다. 전체 버퍼 모드는 오프셋부터 끝까지 해석합니다.
표에는 오프셋·Hex·ASCII를 256바이트씩 표시합니다.
자료형과 엔디언을 선택하며 부동소수점은 형식에 맞는 길이가 필요합니다.
선택 바이트를 복사하거나 바이트를 유지한 채 입력 형식만 바꿀 수 있습니다.

비트필드 편집기를 펼쳐 이름·LSB 기준 오프셋·폭·부호 여부를 지정합니다.
필드 적용은 이름 중복·겹침·범위를 검사하고 값과 색으로 구분한 영역을 보여줍니다.
비트를 편집하면 실제 바이트 버퍼도 바뀝니다. 레이아웃은 JSON으로 저장·불러오며
폭은 선택 범위와 같아야 합니다. 대화형 편집은 선택한 512바이트까지,
Core의 바이트 해석은 64 KiB까지 지원합니다.

## 이진 비교와 일괄 변환

이진 비교는 같은 입력 형식으로 두 버퍼를 받습니다.
명시적으로 0 확장을 선택하지 않으면 길이가 같아야 합니다.
XOR, 변경 비트·바이트 개수, 페이지별 바이트 차이와 선택한 레이아웃의 필드 차이를 봅니다.
비트 차이를 펼치면 최대 4096비트의 색상 뷰를 표시합니다.
더 큰 입력은 바이트·텍스트 뷰와 전체 개수를 제공하고 위치 목록의 잘림 여부를 표시합니다.

일괄 변환은 빈 줄을 건너뛰며 원래 줄 번호를 유지합니다.
숫자·수식·자동 모드, 출력 진법, 자릿수와 행 한도를 고릅니다.
기본 출력은 소수부 16자리이고 정확한 출력은 작업 한도 안에서 전개합니다.
오류 행 때문에 다른 성공 행을 버리지 않습니다. 요약에서 오류와 미처리 입력을 확인하세요.
내보내기에도 행별 값과 오류를 유지합니다.

## 언어·테마·기록

설정 → 환경설정에서 한국어·영어와 시스템·라이트·다크 테마를 선택합니다.
초기 언어는 시스템 지역 설정을 따릅니다.
언어 변경은 입력·옵션·진행 중인 계산·결과 데이터·기록을 유지합니다.
JSON·CSV 키와 내보내는 숫자는 GUI 언어에 따라 바뀌지 않습니다.

최근 기록은 Ctrl+H로 표시합니다. 입력·결과·작업 종류로 검색하고 종류별로 필터링합니다.
캐시가 있으면 결과를 바로 복원하고, 큰 기록은 입력·옵션을 복원한 뒤 실행합니다.
같은 입력·옵션은 중복 추가하지 않고 맨 앞으로 옮깁니다. 기록 삭제는 저장된 항목을 지웁니다.
기록을 꺼도 현재 작업 상태는 별도로 저장합니다.

기록은 기본 20개이며 1~100개를 선택합니다. 개별 결과 캐시는 256 KiB까지입니다.
설정은 기존 스키마와 호환되며 원자적으로 교체하고 파일 크기는 32 MiB로 제한합니다.
읽기·쓰기 실패는 상태 메시지로 안내하며 저장 실패 시 이전 파일을 유지합니다.
CLI는 GUI 설정을 수정하지 않습니다.
