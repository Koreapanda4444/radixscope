# 데스크톱 앱 사용법

[한국어 README](../../README.ko.md) | [English](../desktop.md)

`radixscope-gui` 또는 `python -m radixscope.gui`로 실행합니다.
Ctrl+1~Ctrl+4로 작업 화면을 바꿀 수 있습니다. 주 입력 칸에서 Enter를 누르면 계산합니다.
결과를 선택하거나 **Copy result**로 복사할 수 있습니다. 잘못된 입력은 이전 결과를
지우고 출력 위에 오류를 표시합니다. 아래 설명의 화면 이름과 버튼 이름은 앱에 표시되는
영문 이름을 기준으로 합니다.
창이 작아서 입력 항목이 모두 들어가지 않으면 입력 영역을 가로·세로로 스크롤할 수 있습니다.

## 계산 실행과 취소

각 작업 화면은 계산을 별도 프로세스에서 실행합니다. Calculating 상태에서도 창을
조작할 수 있으며 Cancel은 해당 프로세스를 종료하고 대기 중인 출력을 지웁니다.
입력이나 옵션을 바꾸면 실행 중인 계산을 취소하고 이전 결과를 무효화합니다.
성공한 현재 결과만 최근 기록에 저장하며, 앱을 닫으면 실행 중인 계산을 종료합니다.
데스크톱 결과 전달은 8 MiB까지 허용합니다. 제한에 도달하면 입력이나 과정 단계 수를
줄이세요. 명령줄은 기존처럼 동기적으로 실행합니다.

## Conversion: 진법 변환

선택한 입력 진법의 숫자를 변환하려면 Number, 혼합 진법 수식을 계산하려면
Expression을 선택합니다. 출력 진법은 쉼표로 구분해서 입력합니다.
정확한 출력에서는 순환하는 숫자를 괄호로 묶습니다. 긴 전개가 1000자리 표시 제한에
도달하면 말줄임표와 해당 진법을 표시합니다. 원래 유리수의 정확한 값은 유지합니다.

정확한 출력을 끄면 소수부 자릿수와 반올림 방식을 선택할 수 있습니다.
각 출력 진법에서 지정한 자릿수의 결과를 만듭니다.

## Trace: 변환 과정

정수부 나눗셈 단계, 소수부 곱셈 단계, 결과 숫자, 순환 구간의 시작을 표시합니다.
소수부 최대 단계 수를 조절해서 출력을 제한할 수 있습니다.
`complete: False`는 전개가 끝나거나 순환이 확인되기 전에 단계 제한에 도달했다는
뜻이며, 유한소수라는 뜻은 아닙니다.

## Programmer: 정수와 비트

진법, 비트 폭, 부호 여부를 선택하고 입력을 수학적 정수로 읽을지 원시 비트 패턴으로
읽을지 정합니다. GUI의 비트 폭은 1~4096이며 Python 모델은 임의의 양의 비트 폭을
지원합니다. 패턴 입력은 먼저 부호 없는 숫자로 읽은 뒤 해석하므로, 8비트 부호 있는
설정에서 16진수 `FF`는 -1입니다. 수학적 정수 입력은 선택한 범위 안에 있어야 합니다.

덧셈, 뺄셈, 곱셈, AND, OR, XOR, NOT, 시프트를 지원합니다.
시프트 횟수는 10진수입니다. `shr`은 부호 있는 값에 산술 시프트를 적용하며,
`lshr`은 항상 빈 자리를 0으로 채웁니다. 산술 결과는 정확한 값과 오버플로 여부,
선택한 비트 폭에 맞춰 감싼 값을 함께 보여줍니다. 바이트 미리보기는 비트 폭과
선택한 엔디언 순서를 유지합니다.

결과 비트는 버튼을 클릭하거나 포커스를 두고 Space를 눌러 편집합니다.
최상위 비트부터 최하위 비트 순서이며 페이지당 최대 32비트를 표시합니다.
결과를 편집하면 현재 진법의 원시 패턴으로 입력을 바꾸고 Inspect를 선택하므로
이전 산술 연산을 다시 적용하지 않습니다. 숫자·바이트 결과는 즉시 갱신합니다.
다른 입력 옵션을 바꾸면 편집기를 무효화하며 Run으로 새 결과를 불러옵니다.

## IEEE 754: 부동소수점 표현

Encode는 정확한 수식, NaN, 무한대를 받습니다. Decode는 선택한 패턴 진법의
원시 숫자를 해석합니다. binary32 또는 binary64를 선택할 수 있습니다.
결과에는 유한한 값의 정확한 유리수 표현, 분류, 분리된 비트 필드, 16진수,
엔디언 순서에 따른 바이트가 포함됩니다.

음의 0 옵션은 0을 인코딩할 때 적용합니다. NaN 옵션은 입력이 `nan` 또는
`-nan`일 때 사용할 수 있습니다. Quiet NaN을 끄면 페이로드가 0이 아니어야 합니다.
원시 디코딩에서는 비활성화된 인코딩 옵션을 무시합니다. 모드를 바꿔도 입력 문자는
유지하므로 이어서 편집할 수 있습니다.

비트 편집기는 부호·지수·가수를 이름과 색으로 구분합니다. binary64는 두 페이지를
사용합니다. 비트를 편집하면 Decode로 전환하고 입력을 선택한 진법의 원시 패턴으로
바꿉니다. 분류·정확한 값·16진수·엔디언 바이트·NaN 정보를 함께 갱신합니다.
부호 있는 0과 시그널링 NaN 페이로드를 포함해 모든 원시 비트를 유지합니다.

## 설정과 최근 기록

Settings → Preferences에서 System, Light, Dark 테마와 최근 기록 저장 여부를
선택합니다. 기록 개수는 1~100으로 설정하며 기본값은 20입니다.
현재 입력과 작업 옵션, 선택한 탭, 창 크기는 다음 실행 때 복원합니다.

Recent 패널에는 입력, 옵션, 시각, 짧은 결과 요약을 저장하고 전체 과정 출력은
저장하지 않습니다. 입력과 옵션이 같은 항목은 중복 생성 대신 맨 앞으로 이동합니다.
항목을 두 번 클릭하거나 Restore selected input을 누르면 입력을 복원합니다.
복원한 입력은 Run으로 계산합니다. Clear history는 저장된 최근 기록을 지웁니다.
기록 저장을 끄면 새 항목을 만들지 않지만, 현재 작업 옵션과 입력은 별도로 저장합니다.

계산 성공, 명시적인 설정 변경, 창 닫기 때 설정을 저장합니다.
쓰기에는 설정 파일을 원자적으로 교체하는 방식을 사용합니다. 읽을 수 없거나 형식이
잘못된 설정은 기본값을 사용하고 상태 메시지를 표시합니다. 쓰기 실패 시 이전 파일을
유지하며 계산은 계속할 수 있습니다. 명령줄은 데스크톱 설정을 읽거나 변경하지 않습니다.
설정 파일은 읽기와 저장에 같은 32 MiB 제한을 적용해 긴 입력을 포함한 기록 100개도 저장합니다.
제한을 넘는 저장은 오류를 표시하고 이전 설정 파일을 유지합니다.
