# RadixScope 2.1.0

English | [한국어](../ko/releases/2.1.0.md)

This release adds cancellable desktop calculations, interactive bit editing and a Windows x64
desktop package. The exact numeric core and command line retain their existing semantics.

- All four workspaces calculate in isolated processes, with Cancel and shutdown cleanup.
- Input changes discard pending work and old output; cancelled results never enter history.
- Programmer result bits update signed/unsigned values, the input pattern and byte representations.
- IEEE 754 bits separate sign/exponent/fraction and preserve NaN payloads and signaling bits.
- Bit pages contain at most 32 buttons so binary64 fits the default window without overlap.
- Qt result signals preserve arbitrary-size Python integers instead of coercing them to Qt integers.
- A Windows x64 ZIP includes Python, Qt, an application icon, version information and documentation.
- CI checks lint and types and builds Python packages and the Windows desktop ZIP.

Download the `RadixScope-windows-x64` artifact from a successful
[Quality run](https://github.com/Koreapanda4444/radixscope/actions/workflows/quality.yml), extract both
ZIP layers and run `RadixScope/RadixScope.exe`. Keep `_internal` with the executable.
See [installation](../install.md) and [desktop usage](../desktop.md).

Existing 2.0.0 preferences and history use the same format and location. No settings migration
is needed. The desktop transfer limit is 8 MiB; existing exact-conversion and trace display limits
still apply. Packages are provided through CI artifacts; no public release or PyPI publishing
automation is configured.
